# CIVITAS research outputs

`initial_experiment.md` contains measurements from actually executed baseline runs. Data generated by the CLI is excluded from Git by default to avoid false assumptions of experimental generality. For publication-quality work preserve the raw output files in a versioned research dataset or release.

### Population normalization and market-topology counterexample

See `v02_population_normalization_experiment.md` and the source experiment runners `run_population_normalized.py` and `run_market_partition_control.py`. Original **period-by-period** records and configuration audits are stored under `v02_population_normalized_1000/`, `v02_population_normalized_10000/` and `v02_market_partition_30/`. These files reproduce the results reported in the note without requiring users to infer missing raw observations. All outputs are simulated, not calibrated to historical data.
